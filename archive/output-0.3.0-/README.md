# Gemini Modular Studio

![Mothership Cockpit](https://images.unsplash.com/photo-1551288049-bebda4e38f71?q=80&w=1200&auto=format&fit=crop)

**MOTHERSHIP COCKPIT**

A high-fidelity, modular creative studio inspired by professional audio software. This application serves as a central interface for context awareness, reports, summaries, and event checking, powered by Google's Gemini models.

## Core Modules

*   **Logic Lab**: Interactive diagrams (Flow, Automata, Network) and concept visualization.
*   **Deep Think**: Advanced reasoning engine with "thinking" budget control.
*   **Image Generator**: Pro-level generation with aspect ratio and resolution controls.
*   **Image Editor**: Context-aware editing with vibe presets.
*   **Live Voice**: Real-time multimodal audio/video uplink with oscilloscope visualization.
*   **Synthesizer**: High-quality Text-to-Speech.
*   **Dependency Manager**: Intelligent Python library and dependency analysis.
*   **Research**: Integrated Google Search grounding for live data.

## Visuals

The interface features FabFilter-style modularity, real-time waveform visualization, and a "Code Context" visualizer that reacts to different input modalities (Text, Voice, Image, Processing).

## Setup

1.  Obtain a Google GenAI API Key.
2.  Install dependencies.
3.  Launch the cockpit.
