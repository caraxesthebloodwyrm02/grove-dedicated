# Doc heatmap (Lo7) — static output

The HTML **heatmap** is generated by the Python CLI; this directory is a logical home for runbooks or any optional static export.

**Generate:**

```bash
uv run lo7-manifest --config lo7_corpus.yaml --out _lo7/manifest.json
uv run lo7-heatmap --in _lo7/manifest.json --out _lo7/heatmap.html
# Optional display-only motion (§9, no audio):
# uv run lo7-heatmap --in _lo7/manifest.json --out _lo7/heatmap.html --motion
```

**Rules:** The renderer may read only the manifest JSON — it does not re-walk the repository (see `tools/octopus/BENCHMARK.md` and §2.1 in the project plan).
