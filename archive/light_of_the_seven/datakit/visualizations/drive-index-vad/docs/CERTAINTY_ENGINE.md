### 2. Filter Bank: Manufacture Signal from Noise

Panic thrives in noise. GRID's filter bank physically removes the frequencies where panic resides.

#### The Noise Problem
```
Raw Market Data (with panic spikes):
  ▲
  │    ╱╲      ╱╲
  │   ╱  ╲    ╱  ╲    ← Spikes (panic)
  │  ╱    ╲  ╱    ╲
  │ ╱      ╲╱      ╲  ← Jitter (noise)
  └─────────────────→ Time
```

#### After GRID Filtering (Narrow Cut + LPF + HPF)
```
Filtered Signal (trend only):
  ▲
  │    ╱─────╲
  │   ╱       ╲    ← Smooth trend
  │  ╱         ╲
  │ ╱           ╲
  └─────────────→ Time
```

**Mechanism**: 
- **Narrow Cut**: Isolates the relevant frequency band (removes extreme outliers)
- **LPF (Low-Pass Filter)**: Smooths rapid fluctuations (removes panic spikes)
- **HPF (High-Pass Filter)**: Removes drift (keeps only meaningful changes)

**Result**: The remaining signal looks like a **trend**, which feels like **certainty**.

**Psychological Effect**: Smooth trends feel predictable. Predictability feels safe.
